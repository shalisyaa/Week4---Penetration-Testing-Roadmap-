# Week4---Penetration-Testing
Networkwalk Internship Journey

## Project Overview
This was a black box penetration test of the Mediroza General Hospital website as part of my cybersecurity training with Networkwalks.

The aim was to work out how security flaws can be discovered via reconnaissance, access control assessment, file security analysis and information security assessment.

## Scope and Activities

The project was divided into four main milestones:

1. Initial access: carried out some reconnaissance, looked at the publicly available website info and the authentication areas.
2. Data Extraction and File Analysis – looked at file security and the various ways of going about the analysis of encrypted files.
3. Information gathering – looked at the available information to assess the potential exposure risks relating to organisational and internal data.
4. Penetration Testing Report – the assessment process, findings, issues and security recommendations have all been collated into a report.

## Tools and Techniques
The practical involved working with:

- Kali Linux
- Linux command-line utilities
- DNS and network troubleshooting
- Website reconnaissance
- HTTP response and header inspection
- `robots.txt` and XML sitemap analysis
- File and encryption analysis
- Password-cracking tools introduced during training

## Challenges and Learning Experiences

We ran into a number of problems during the course of this project, particularly with getting the networking sorted and with DNS in the Kali Linux VM. I also had a bit of a problem with the document analysis, particularly when looking at various approaches to the encrypted files and trying to work out what the organisation was actually doing. These challenges have given me a real improvement in my ability to troubleshoot, a much better understanding of the actual methodologies used in penetration testing and a far greater familiarity with the range of Linux based security tools.

## Key Takeaways

This project provided practical exposure to several important cybersecurity concepts:

- Understanding the reconnaissance phase of a penetration test.
- Identifying information about publicly exposed websites.
- Understanding the authentication and access control considerations.
- Learning the impact of file encryption on data security.
- The absolute imperative of protecting sensitive organisational information.
- Documenting the technical observations in a professional penetration testing report.

## Conclusion

Overall it's been a very useful project in terms of applying the cybersecurity concepts in a practical assessment type environment. It really did improve my understanding of the penetration testing process, gave me a lot more confidence in using Kali Linux and has definitely helped me with my problem solving and analytical skills. Most importantly I learned that penetration testing is about far more than just finding the vulnerabilities. It's about doing it responsibly, doing the analysis properly, producing good documentation and good recommendations that actually help to improve the security of the system.

**Note:** This repository contains a general overview of the learning experience only. Technical evidence, confidential information and sensitive assessment findings have been deliberately excluded in order to protect confidentiality.
